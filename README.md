# Energy Conservation Week 2027 (ECW 2027) | VIT Chennai

Official website for **Energy Conservation Week 2027**, organized by the **School of Electrical Engineering (SELECT), VIT Chennai** in association with **HAVELLS India Limited**.

> **Theme**: *"Save Energy, Secure Energy: Towards Viksit Bharat 2047"*  
> **Dates**: 15 – 19 March 2027  
> **Tagline**: *"Conserve Energy, Conserve Tomorrow"*

---

## 🌟 Key Features

- **Official Poster & PDF Showcase**: Includes high-resolution poster graphics and direct download for `ECW_Poster_Revised_v2.pdf`.
- **HAVELLS Collaboration**: Dedicated branding and highlights celebrating industry partnership with Havells India Limited.
- **6 Flagship Events & Competitions**:
  1. Expert Talk / Guest Lecture
  2. Student Projects / Innovations
  3. Poster & Slogan Competition
  4. Energy Awareness Quiz
  5. Campus Energy Audit (Student Drive)
  6. BEST Energy Saver (Department / Lab Award)
- **Be an Energy Champion!**: 6 golden rules of energy thrift from the official poster.
- **Campus Energy Savings Calculator**: Interactive sliders to estimate monthly kWh conserved, money saved (₹), and CO₂ avoided.
- **Virtual Energy Pledge**: Generate and print an Energy Champion Citation Certificate.
- **Leadership & Organizing Committee**: Featuring Chancellor Dr. G. Viswanathan, Patrons, and Convenor Dr. Lenin N C (Dean, SELECT).

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/ASINRAJA123/vit.git

# Navigate into project directory
cd vit

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
